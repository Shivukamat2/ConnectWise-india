# ConnectWise India

ConnectWise India is a modern telecom comparison and network intelligence platform designed to help users compare internet and mobile plans, explore routers and Wi-Fi solutions, check simulated network coverage, and perform network diagnostics.

## Features

- Internet plan comparison
- Mobile network comparison
- Router & Wi-Fi catalog
- Network diagnostic dashboard
- Network coverage exploration
- Plan comparison
- Search functionality
- Location selection
- Responsive interface
- Reports and insights
- Checkout/order flow

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Lucide React
- React Router
- Local state and browser storage

## Status

V5 — Stable Reference Build

The project is actively being developed and improved.

## Disclaimer

Some network measurements, coverage information, and telemetry are simulated or estimated for demonstration and research purposes unless explicitly identified as measured or provider-sourced.
